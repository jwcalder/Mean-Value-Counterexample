# p-Harmonic Mean-Value Counterexample

This repository contains the Python code for numerical examples and the C++ code for the computer assisted proofs from the paper 

Ángel Arroyo, Jeff Calder, and Mikko Parviainen, 2026. [A counterexample to the pointwise validity of an asymptotic mean value property for p-harmonic functions](https://arxiv.org/abs/2609.28069). arXiv:2609.28069.

The script `shooting.py` in the `python` folder runs all non-rigorous experiments and generates plots. There is a detailed README.md in the `cap-code` directory explaining the computer assisted code, which is also archived on [Zenodo](https://doi.org/10.5281/zenodo.22904461).
